## 🚀 QUICK START (3 STEPS)

### Step 1: Upload (5 minutes)
Upload these 3 files to your web server:
- chatbot.js
- chatbot-data.js
- chatbot.css

### Step 2: Add Code (10 minutes)
Add this to the `<head>` of **every HTML page**:
```html
<link rel="stylesheet" href="chatbot.css">
<script src="chatbot-data.js"></script>
<script src="chatbot.js"></script>
```

### Step 3: Test (5 minutes)
Open your website and click the 🤖 button in bottom-right corner.

**Total Time: 20 minutes**
