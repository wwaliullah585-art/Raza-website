Complete Integration Guide for Your Website

⚡ Quick Start

To add the chatbot to any page, include these 2 lines in the <head> section:

<link rel="stylesheet" href="chatbot.css">
<script src="chatbot-data.js"></script>
<script src="chatbot.js"></script>

That's it! The chatbot will appear automatically on all your pages.

📁 Files Created

  • chatbot.js - Main chatbot logic and functionality
  • chatbot-data.js - Website content database
  • chatbot.css - Modern styling and animations
  • INTEGRATION_GUIDE.html - This documentation file

📋 Step-by-Step Integration Guide

Step 1: Verify All Files Are in Place

Make sure you have uploaded these 3 files to your website root directory:

  • chatbot.js
  • chatbot-data.js
  • chatbot.css

Files should be in the same directory as your HTML pages.

Step 2: Add Script Tags to Your HTML Pages

Open each HTML file (index.html, about.html, services.html, etc.) and add these lines before the closing </head> tag:

<!-- Kondee AI Chatbot -->
<link rel="stylesheet" href="chatbot.css">
<script src="chatbot-data.js"></script>
<script src="chatbot.js"></script>

✅ Important: The order matters! Load CSS first, then data, then main script.

Step 3: Ensure Font Awesome is Loaded

Your pages must have Font Awesome icons included. Look for this line in your <head>:

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">

If you don't have it, add it to each page's <head> section.

Step 4: Test the Chatbot

Open your website in a browser. You should see:

  • A floating purple button in the bottom-right corner (with robot icon)
  • Click it to open the chat window
  • Try typing a question like: "What courses do you offer?"

🎨 Customization Guide

1. Update Website Content

The chatbot's knowledge comes from chatbot-data.js. To add new information:

const websiteData = {
  home: {
    title: "Your Title",
    content: "Your content here..."
  },
  // Add more sections...
};

Each section needs:

  • title - Section name
  • keywords - Words that trigger this section
  • content - The actual information to display

2. Add More Keywords

To make the chatbot smarter, add more keywords to keywordMap:

const keywordMap = {
  "your keyword": ["section_name"],
  "another keyword": ["section_name"],
};

3. Change Colors

Edit the CSS variables at the top of chatbot.css:

/* In chatbot.css */ #kondee-chatbot { --primary-color: #3498db; --secondary-color: #2c3e50; --accent-color: #e74c3c; /* Change these hex colors to customize */ }

4. Change Chatbot Name

In chatbot.js, find the greeting message and change "Kondee AI":

<p>👋 Hi there! I'm Kondee AI, your personal website assistant...</p>

5. Adjust Chat Window Size

Edit these CSS properties in chatbot.css:

.chat-window { width: 420px; /* Change width */ height: 600px; /* Change height */ bottom: 100px; /* Distance from bottom */ right: 30px; /* Distance from right */ }

⚙️ Advanced Configuration

Programmatic Control

You can control the chatbot with JavaScript:

// Toggle chat window
window.kondeeAI.toggleChatWindow();

// Send a message programmatically
window.kondeeAI.sendMessage("What courses do you offer?");

// Clear chat history
window.kondeeAI.clearChatHistory();

// Add a message manually
window.kondeeAI.addMessageToChat("Hello!", "bot");

Customize Response Delay

In chatbot.js, find the sendMessage function and adjust the timeout:

setTimeout(() => {
  // Currently: 600-1000ms delay
  // Change to: 1000-1500ms for slower response
}, 600 + Math.random() * 400);

Disable Chat History

If you want to disable localStorage (for privacy), comment out these lines in chatbot.js:

// this.saveChatHistory();   // Comment out
// this.loadChatHistory();   // Comment out

❓ Frequently Asked Questions

Q: The chatbot isn't appearing on my page. What's wrong? ▼
A: Common issues:
  • Make sure all 3 files (chatbot.js, chatbot-data.js, chatbot.css) are in the correct directory
  • Check that the file paths in your script tags are correct
  • Verify Font Awesome is loaded (needed for icons)
  • Check browser console (F12) for JavaScript errors
  • Clear browser cache and reload the page
Q: How do I add new content the chatbot can answer about? ▼
A: Edit chatbot-data.js:
  1. Add a new section to the websiteData object
  2. Include title, keywords, and content
  3. Add keywords to the keywordMap that point to your new section
  4. Save and reload your page
Q: Can I integrate this with a real AI like ChatGPT or Google's API? ▼
A: Yes! The current system uses keyword matching for reliability and cost-effectiveness. To add real AI:
  1. Replace the generateBotResponse() function in chatbot.js
  2. Add API calls to OpenAI, Google, or other services
  3. Handle API keys securely (use a backend server, not frontend)
  4. Note: This requires a backend server and adds costs
Q: The button is covering my content. How do I move it? ▼
A: Edit chatbot.css and find the .chatbot-button class: 
.chatbot-button {
  bottom: 30px;  /* Change this value */
  right: 30px;   /* Or change this value */
}
Increase the numbers to move it further away from the corner.
Q: Can I customize the chat window appearance? ▼
A: Yes! All styling is in chatbot.css. You can customize:
  • Colors: Edit the CSS variables at the top
  • Size: Modify .chat-window width/height
  • Fonts: Change the font-family declarations
  • Animations: Modify the @keyframes rules
Q: Does the chatbot work offline? ▼
A: Almost! As long as your website is accessible, the chatbot works. It doesn't require any external APIs by default (unlike ChatGPT). Font Awesome icons need internet to load from CDN, but the chatbot functionality itself is completely local.

🔧 Troubleshooting

Issue: Console shows "generateResponse is not defined"
Solution: Make sure chatbot-data.js is loaded BEFORE chatbot.js
Issue: Chat button doesn't respond to clicks
Solution: Check that JavaScript isn't blocked. Verify console has no errors (F12).
Issue: Styling looks wrong (button misaligned, etc.)
Solution: Make sure other CSS isn't overriding chatbot CSS. Check for conflicting z-index values.
Issue: Chat history isn't saving
Solution: Browser localStorage might be disabled in incognito mode. Works fine in normal mode.
