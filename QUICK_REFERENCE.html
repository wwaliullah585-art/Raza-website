🚀 Kondee AI - Quick Reference Card

⚡ Installation (3 Steps)

Upload 3 files to your server
  • chatbot.js
  • chatbot-data.js
  • chatbot.css
Add to each HTML page
<link rel="stylesheet" href="chatbot.css"> <script src="chatbot-data.js"></script> <script src="chatbot.js"></script>
Click the 🤖 button to test
✓ Ready to Deploy

📋 Required in HTML

Must have Font Awesome:

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">

Add these BEFORE </head>:

<!-- Chatbot --> <link rel="stylesheet" href="chatbot.css"> <script src="chatbot-data.js"></script> <script src="chatbot.js"></script>
⚠️ Order matters! CSS first, then data, then script.

📁 File Locations

All files should be in the same directory:

yourwebsite.com/ ├── index.html ├── about.html ├── services.html ├── chatbot.js ⭐ ├── chatbot-data.js ⭐ └── chatbot.css ⭐

Or in a subfolder:

<link rel="stylesheet" href="js/chatbot.css"> <script src="js/chatbot-data.js"></script> <script src="js/chatbot.js"></script>

🎨 Customize Colors

Edit chatbot.css:

#kondee-chatbot { --primary-color: #3498db; --secondary-color: #2c3e50; --accent-color: #e74c3c; }

Change these hex colors to your brand colors

📍 Move Button Position

Edit chatbot.css:

.chatbot-button { bottom: 30px; /* Distance from bottom */ right: 30px; /* Distance from right */ width: 60px; /* Button diameter */ height: 60px; }

Increase numbers to move further away

📐 Resize Chat Window

Edit chatbot.css:

.chat-window { width: 420px; /* Chat window width */ height: 600px; /* Chat window height */ bottom: 100px; /* Distance from bottom */ right: 30px; /* Distance from right */ }

Default: 420px × 600px

📝 Update Website Content

Edit chatbot-data.js:

const websiteData = { home: { title: "Home Page", keywords: ["home", "welcome"], content: "Your home page content here..." }, about: { title: "About", keywords: ["about", "who", "company"], content: "Your about page content..." }, services: { title: "Services", keywords: ["services", "courses", "offerings"], content: "Your services/courses..." } };

🔍 Add More Keywords

Edit keywordMap in chatbot-data.js:

const keywordMap = { "data science": ["datascience"], "machine learning": ["datascience"], "python": ["datascience"], "contact": ["contact"], "email": ["contact"], "phone": ["contact"] // Add more keywords... };

The words you add here trigger corresponding sections above

💻 JavaScript Control

Control chatbot with JS:

// Toggle chat window window.kondeeAI.toggleChatWindow(); // Send message window.kondeeAI.sendMessage("Hello!"); // Clear chat window.kondeeAI.clearChatHistory(); // Add message window.kondeeAI.addMessageToChat( "Hi!", "bot" );

🧪 Testing Checklist

Button appears in bottom-right
Click button opens chat window
Can type and send messages
Receives relevant responses
Works on mobile
Chat history saves

Test questions:

  • "Tell me about data science"

🐛 Troubleshooting

Problem Solution
Button not showing Check chatbot.css path
No icons Load Font Awesome CDN
Not clickable Check console errors (F12)
Wrong responses Update keywords in chatbot-data.js
Styling broken Check CSS file path

📄 Perfect HTML Template

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Page Title</title> <!-- Font Awesome (REQUIRED) --> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css"> <!-- Chatbot (ADD THESE 3 LINES) --> <link rel="stylesheet" href="chatbot.css"> <script src="chatbot-data.js"></script> <script src="chatbot.js"></script> </head> <body> <!-- Your content --> </body> </html>
